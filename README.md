# 🧹 Data Cleaning & Reporting Automation

## 📖 Overview
This project automates data cleaning and reporting using the Customer Personality Analysis dataset. It handles missing values, removes duplicates, transforms data, generates visual reports, and creates automated business insights.

## 🚀 Features
- 🧹 Missing Value Handling
- 🔄 Duplicate Removal
- 📊 Automated Summary Reports
- 📈 Data Visualization
- 👥 Customer Analysis
- 💰 Spending Analysis
- 📄 Excel & CSV Report Generation

## 🛠️ Technologies Used
- 🐍 Python
- 📊 Pandas
- 🔢 NumPy
- 📈 Matplotlib
- 🎨 Seaborn
- 📑 OpenPyXL
- ☁️ Google Colab

## 📂 Dataset
Customer Personality Analysis Dataset containing:
- Customer Demographics
- Income Information
- Education Details
- Marital Status
- Product Purchases
- Campaign Responses

## 📊 Reports Generated
- Customer Summary Report
- Missing Values Report
- Spending Analysis Report
- Campaign Performance Report
- Cleaned Dataset Export

## ▶️ How to Run
1. Upload `marketing_campaign.csv`
2. Run the notebook in Google Colab
3. View automated reports and visualizations
4. Export cleaned data and Excel reports

## 🎯 Project Outcome
Automated the complete data cleaning and reporting workflow, improving data quality and generating business insights through visual and analytical reports.
